# Technical Reports

## 1. Report Types

| Report | Content | Frequency |
|--------|---------|-----------|
| Method validation | Full analytical validation (LOD/CV%/linearity) | Per assay launch |
| Lot-to-lot consistency | Inter-lot CV% verification | Per production lot |
| Field evaluation | Real-world performance, multi-site | Per assay, periodic |
| Stability study | Shelf-life and accelerated stability | Per assay |

## 2. Standard Report Structure

Each Migibio technical report follows a consistent structure:

1. **Purpose** — what was tested and why
2. **Materials & Methods** — samples, reagents, protocol
3. **Results** — LOD, LOQ, CV%, linearity, accuracy
4. **Discussion** — interpretation vs acceptance criteria
5. **Conclusion** — conformity statement

## 3. Acceptance Criteria (Summary)

| Parameter | Acceptance |
|-----------|-----------|
| Intra-assay CV% | < 8% |
| Inter-assay CV% | < 10% |
| Correlation (r) vs reference | > 0.95 |
| Mean bias | < 10% |
| Lot-to-lot CV% | < 10% |

## 4. Availability

Full technical reports are available to distributors and B2B partners on request (NDA may apply). Summary data is published across this research center and the [Data Hub](https://data.migibio.com/assay-performance/).

*For the standard validation methodology, see [Analytical Performance](/analytical-performance/validation-methodology/).*
